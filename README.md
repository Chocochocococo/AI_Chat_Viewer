# AI 聊天室備份檢視器

瀏覽 ChatGPT 與 Claude 匯出備份的本機網頁工具，重點是看得到每則訊息的所有分支（重新生成過的回覆、編輯過的提問）。

純本機執行，不連外網，資料不會離開你的電腦。

## 怎麼用

1. 下載你的備份，會收到一封信，裡面有 zip：

   | 服務 | 位置 |
   |---|---|
   | ChatGPT | 設定 → 資料控制 → 匯出資料 |
   | Claude | Settings → Privacy → Export data |

2. 解開這個壓縮檔，把下載到的備份 zip 直接丟進同一個資料夾（不用自己解壓）：

       任意資料夾/
         AI備份檢視器.exe
         某某備份.zip
         _viewer/

3. 雙擊 AI備份檢視器.exe

第一次會自動解壓並轉檔（約 1～3 分鐘，畫面有進度），然後開瀏覽器；之後直接進畫面。備份 zip 解完可以移走，整個資料夾可壓縮帶到別台電腦。

## 幾個重點

| 情況 | 結果 |
|---|---|
| 兩家的 zip 放同一個資料夾 | 合併成一份清單，可切換只看某一家 |
| 之後丟入新的備份 zip | 自動匯入、依對話合併，不會重複 |
| 對話已在新備份中消失 | 保留舊備份那版，標示「舊備份」 |
| 已解壓好的匯出資料夾 | 把 _viewer 和 exe 放進去即可 |

## 需要安裝什麼

| 方式 | 需求 |
|---|---|
| exe | 什麼都不用裝 |
| Python | 3.8 以上，不需要 pip install 任何套件 |

用 Python 跑：Windows 雙擊 `_viewer\啟動檢視器.cmd`，Mac / Linux 執行 `sh start.sh`。

exe 沒有數位簽章，Windows 可能跳「不明發行者」或防毒誤判，這是 PyInstaller 打包的通病。介意的話改用 Python 版，或自己執行 `python build-exe.py` 重新打包。

## 主要功能

- 分支：訊息上方的 `‹ 2/3 ›` 切換版本，右上角「分支圖」看整棵樹
- 搜尋：搜標題，或全文搜尋所有訊息內容（涵蓋所有分支）
- 匯出：單一對話存成獨立 HTML、Markdown，或 SillyTavern 的 JSONL
- 名稱：可把「你 / ChatGPT」換成自訂名字，只改顯示不動原始文本
- 檔案：GPT檔案庫（圖片與附件）、Claude專案知識庫（專案上傳的檔案）
- 版面：側欄可收合（左上角 « 或 Ctrl+B），小螢幕預設收起
